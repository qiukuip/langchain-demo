# 工具调用前端示例

一个可在浏览器中运行的 Ollama 工具调用示例。模型可以请求计算、模拟天气和模拟搜索；页面展示调用参数、执行结果及后续回答。工具不请求外部 API。

## 准备

- Node.js 18+
- 已安装并运行的 Ollama
- 一个支持工具调用的 Ollama 模型，例如 `llama3.1`

```bash
ollama pull llama3.1
ollama serve
```

如果 Ollama 已作为系统服务运行，无需再次执行 `ollama serve`。

## 启动

在本目录执行：

```bash
npm install
npm start
```

打开 <http://localhost:3000>。开发服务器把 `/api/*` 代理到本机 Ollama 的 `127.0.0.1:11434`。页面会读取已安装模型；建议选择支持工具调用的模型。

## 工具

| 工具 | 行为 | 数据来源 |
| --- | --- | --- |
| `calculate` | 解析并计算四则运算、小数、括号和取余 | 本地浏览器 |
| `get_weather` | 根据城市名生成稳定的模拟天气 | 本地浏览器 |
| `search_web` | 根据关键词返回三条模拟搜索摘要 | 本地浏览器 |

天气和搜索数据纯属演示，不能用于获取真实信息。工具出错时，错误会显示在卡片中并传回模型。为了避免模型无休止调用工具，单次提问最多执行 6 轮模型请求。切换模型或清空对话会重置上下文。

## 构建

```bash
npm run build
```

生产部署需要把 `/api/*` 反向代理到 Ollama，或按部署环境调整 `src/agent.js` 中的请求路径。不要把没有访问控制的 Ollama 服务直接暴露到公网。

这个目录是纯前端示例，直接使用 Ollama 的聊天与工具调用协议；仓库其他目录展示 LangChain/LangGraph 的服务端用法。
